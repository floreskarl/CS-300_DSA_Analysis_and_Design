Reflection
What problem was I solving in the projects for this course?
Across both projects, the main problem was designing a system that could store course data, search for specific courses, and print the full course list in sorted order. Project One focused on analyzing how different data structures behave in terms of runtime and memory. Project Two required building a working program that performs these operations efficiently.

How did I approach the problem? Why are data structures important?
I approached the problem by comparing the strengths and weaknesses of three data structures: vectors, hash tables, and binary search trees. Data structures are important because the choice directly affects performance. For example, vectors require O(n) search time, hash tables offer average O(1) lookup, and binary search trees provide sorted order with O(log n) search when balanced. Understanding these tradeoffs helped me choose the right structure for each task.

How did I overcome roadblocks during the activities or project?
I encountered challenges with file parsing, pointer management, and ensuring the BST printed in correct alphanumeric order. I overcame these by breaking the problem into smaller steps, testing each function independently, and revisiting the algorithmic logic when something didn’t behave as expected. Debugging in CLion and using print statements helped verify that each part of the tree was being built correctly.

How has this project expanded my approach to designing software?
This project made me more intentional about why I choose certain data structures instead of just making something work. I now design programs by considering expected input size, lookup frequency, memory constraints, whether sorted output is required, and how expensive insertion or deletion will be. It pushed me to think more analytically about design choices.

How has this project evolved the way I write maintainable, readable, and adaptable code?
I’ve become more consistent with function naming, modular design, and separating responsibilities. I created dedicated functions for loading data, inserting nodes, and printing the tree instead of mixing everything together. I also added comments explaining algorithmic decisions, which makes the code easier to revisit later. Overall, I write cleaner, more structured code that can be extended without rewriting everything.
